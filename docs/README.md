# Nxance docs

Reference material pulled from the Nxance Google Drive folders. Refresh with `scripts/sync-drive-docs.sh`.

| --- | --- |

| `engines/` | v3.1 HTML prototypes: Construction Engine, HealthCheck Engine, NxanceLM. Open in a browser. `previous/` holds older copies. |

| `brand/` | `logo.png` |
| `business-canvas/` | Lean canvas and business model canvas. |
| `business/decks/` | Investor deck, pitch deck, grant pitch deck (`.pptx`/`.pdf`). |
| `business/one-pagers/` | One-pagers, grant one-pagers, company information. |
