E-04 — RISK ANALYSIS ENGINE
Same Target. Less Risk.
7 risk metrics. 3-level decision tree. Approves, rebalances, or rebuilds.
7 Risk Metrics Tracked
Sharpe RatioTarget above 0.8. Formula: (Return - 6.5%) / Volatility
CVaR 95%Avg loss in worst 5% scenarios. Target above -12%/yr
Max DrawdownPeak-to-trough. Must stay within user risk limit.
VaR 95%Worst single day with 95% confidence
Goal ProbabilityMonte Carlo % of hitting target. Must stay above 65%.
Concentration RiskNo single instrument above 40% of portfolio
Correlation RiskAll instruments moving together? Systemic risk flag.
3-Level Decision Tree
def risk_decision(metrics, user): # LEVEL 1: CRITICAL -- Full Rebuild if metrics.sharpe < 0.3: return trigger(E01.rebuild) if metrics.goal_probability < 50: return trigger(E01.rebuild) if metrics.concentration > 0.60: return trigger(E01.rebuild) # LEVEL 2: WARNING -- Rebalance if metrics.max_drawdown > user.tolerance: return trigger(E06.rebalance) if metrics.concentration > 0.40: return trigger(E06.rebalance) if drift_detected(): return trigger(E06.rebalance) # LEVEL 3: ALERT -- Notify Only if metrics.goal_probability < 65: notify(user, 'goal_probability_low') return 'APPROVED'
Core principle: If Rs.50L target reachable with 60% equity (Sharpe 0.9) AND 65% equity (Sharpe 0.9) — always recommend 60%. Same destination, lower risk.

E-06 — REBALANCING ENGINE
Drift Detected. Restore Balance.
3 triggers. Tax-optimized. Max once per 90 days normally.
3 Triggers
Allocation DriftAny asset class drifts more than 5% from target. Example: Large Cap target 30%, now at 38% after bull run.
Risk Metric BreachMax drawdown exceeds user limit. Concentration above 40%. Goal probability drops below 50%.

What E-06 Will NOT Do
Will NOT rebalance on 2-3% drift (too many transactions). Will NOT rebalance more than once per 90 days. Will NOT sell winners unless risk metrics demand it.
Tax-Optimized Algorithm
def rebalance(portfolio, targets): trades = [] for asset in portfolio: drift = current_weight - target_weight if abs(drift) > 0.05: trades.append({ 'action': 'SELL' if drift > 0 else 'BUY', 'rs': abs(drift) * portfolio.total_value, 'unrealized_gain': asset.unrealized_gain }) # Tax optimization: # Sell assets at LOSS first (tax-loss harvesting) # This offsets capital gains tax on profitable sells sells = [t for t in trades if t['action']=='SELL'] sells.sort(key=lambda x: x['unrealized_gain']) # Losses first return sells + [t for t in trades if t['action']=='BUY']
Tax-loss harvesting can save Rs.10,000-40,000/year in capital gains tax on a Rs.10L portfolio by selling losers first to offset the gains from selling winners.
