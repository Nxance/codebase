M-01XIRR — Real Annual Return15%
NPV(r) = ∑[ CF_i / (1+r)^t_i ] = 0 → r = XIRR
from scipy.optimize import brentq def calculate_xirr(holdings): cfs, dates = [], [] for h in holdings: cfs.append(-h.invested_amount) dates.append(h.purchase_date) cfs.append(sum(h.current_value for h in holdings)) dates.append(datetime.today()) d0 = dates[0] t = [(d - d0).days / 365.25 for d in dates] npv = lambda r: sum(c/(1+r)**ti for c,ti in zip(cfs,t)) return round(brentq(npv, -0.9999, 10.0) * 100, 2)
XIRR Compared Against
Goal-Required XIRRWhat % return is needed to reach Rs. target by deadline? Most important comparison.
Nifty 50 (14.5%/yr)20-year automatic index return. Main benchmark for active funds.
Category AverageIs this fund beating its category peers? If not, Selection Engine triggered.
Inflation (6.5%)Real return = XIRR minus 6.5%. Must be positive. If negative, goal is eroding.
FD Rate (7.0%)Minimum acceptable. Equity risk must earn more than FD.
Selection Engine Trigger: XIRR below goal-required rate → find instruments to improve portfolio XIRR to target. XIRR below Nifty 50 → find Index fund alternatives with 0.06-0.20% TER.
