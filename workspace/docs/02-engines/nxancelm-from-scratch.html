Rs. Number Formatter"Rs.6,240" → single token. Indian number system (lakh, crore) natively supported.

Finance Domain Layer — The Key Difference
# Standard transformers: generate text freely # NxanceLM: Rs. numbers are GROUNDED, not generated class FinanceDomainLayer(nn.Module): """Extra layer that prevents number hallucination""" def forward(self, hidden_states, query_context): # Before generating any number (Rs., %, ratio): # 1. Check if number exists in live data cache # 2. If YES: use exact number from API # 3. If NO: explicitly say "I don't have this data" detected = self.detect_number_generation(hidden_states) if detected.is_financial_number: live_val = self.live_data_cache.get( detected.entity_type, detected.entity_id) if live_val: return self.force_grounded_number(live_val) else: return self.generate_uncertainty_token() return self.standard_forward(hidden_states)
This finance domain layer is why NxanceLM never says "TER is approximately 1.2%" when the real TER is 1.68%. It checks AMFI API first, always.

Upcoming IPO kaun sa best hai is quarter mein?
NXANCELM — IPO ANALYSIS FRAMEWORK NxanceLM scores every IPO on 6 factors before suggesting. Here is the framework for any IPO:

Factor 1 — Valuation: P/E vs listed peers. If IPO P/E is 40x but listed peers trade at 25x = overvalued. Avoid.
Factor 2 — Revenue Growth: Must be above 20%/year for 3 years. Slowing growth + high valuation = red flag.
Factor 3 — Use of Proceeds: Expansion capex = good. OFS (promoters cashing out) = red flag. Check DRHP Section II.
Factor 4 — Promoter Post-IPO Holding: Above 50% = aligned interests. Below 30% = promoter is exiting.
Factor 5 — GMP (Grey Market Premium): High GMP = listing gain possible, not investment quality. These are separate decisions.
Factor 6 — Anchor Quality: Top MFs (SBI, HDFC, Mirae) participating = institutional confidence signal.

Important: GMP-based IPO investing ≠ portfolio building. Nxance focuses on long-term portfolio quality. For specific upcoming IPO analysis, share the IPO name and I will run all 6 factors.
