Technology — MVP Stack
What we're building with and why — for IndiaAI, MeitY, deep tech grants
NxanceLM — key innovation descriptionLead with this in every tech application
For IndiaAI Mission / MeitY forms
Nxance's core technical innovation is NxanceLM — a proprietary financial language model trained entirely in India on Indian financial data. Base: TinyLlama 1.1B (open source). Method: LoRA (Low-Rank Adaptation) — reduces trainable parameters from 1.1B to 4.2M (99.6% reduction). Training: 200+ curated Q&A examples from AMFI scheme data, NSE market data, SEBI circulars, and real portfolio scenarios. Training infrastructure: Free Google Colab T4 GPU — 2 hours, Rs 0 cost. Model size: 12MB adapter file. Inference cost: Rs 0 per query (no external API). This makes Nxance the only Indian fintech running its own trained LLM — vs competitors paying Rs 5–50 per query to OpenAI/Gemini. At 1 lakh queries/day, this saves Rs 50,000–5,00,000/day in API costs.
