# Nxance — 5-minute client demo (Abhiyan-style)

## Goal

Show a **working** product: live engines, real numbers, mobile path, unlock path — not slides.

## Prep (2 minutes)

1. API running: `cd product/mbp && ./run.sh`
2. Open laptop browser: `http://127.0.0.1:8000/demo` (auto tour)
3. Optional: install APK on phone / emulator
4. Video backup: `product/releases/demo_video/Nxance_Product_Demo.mp4`

## Live script

> “Most apps invent advice. Nxance **measures** first.”

Open `/demo` and let the tour run, or click through web portal.

### 0:30 — Login
> “Demo auth — name + phone, no OTP bill. Guest works too.”

### 1:00 — Sample health
> “One click on a **labelled sample**. Score, TER waste ₹/yr, overlap. Not your money — engines still real.”

### 2:00 — Intelligence stack
